# PB Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the Time Trial session code (13), store sector times with each PB, send the full TT PB list to the phone, and replace the phone's Car page with a PB page.

**Architecture:** `RaceTracker` passes S1/S2 with each completed lap; `PbStore` keeps them and can list all TT PBs; a new HMAC'd PB-list packet (marker `0xFFFFFFFB`) goes to the phone every 2 s and right after a new PB; the phone decodes it into a `StateFlow<List<TrackPb>>` shown by a new `PbView` at centre page 1 (CarView deleted).

**Tech Stack:** C# / .NET 8 / xUnit; Kotlin / Compose / JUnit.

**Spec:** `docs/superpowers/specs/2026-11-20-pb-page-design.md` (builds on `2026-11-19-pb-recorder-and-bigger-buttons-design.md`).

## Global Constraints

- F1 2021 only. **Time Trial = session type 13** (observed in the user's pbs.json: `"3/13/dry"`).
- S3 = Ms − S1 − S2; S1 = S2 = 0 means "no sectors" (old entries) -> phone shows `—`.
- PB-list packet: `[marker:u32 0xFFFFFFFB][count:u8]` + per track `[trackId:i8][dryMs:u32][dryS1:u16][dryS2:u16][wetMs:u32][wetS1:u16][wetS2:u16]` (17 bytes, LE, 0 = none). Max 50 tracks (fits 1024-byte phone buffer incl. auth trailer).
- Phone receive buffer 256 -> 1024 bytes. Old phones ignore the unknown marker.
- Commits: **no Co-Authored-By trailer** (user rule).

## Review Focus

- Existing pbs.json (`{"3/13/dry":{"Ms":86839,"Date":"..."}}`, no S1/S2) must load and show lap times with `—` sectors — the user's real data.
- A truncated/garbled PB-list packet (count says 5, bytes for 2) must not crash the phone or wipe the shown list.
- No phone connected / no telemetry (`--no-telemetry`): the 2 s send loop must not throw or spin.
- PB page with zero PBs, or current track unknown (-1), must render a sensible empty state, not crash.
- A sector > 65.535 s can't happen (the game's own sector fields are u16 ms); don't add handling.
